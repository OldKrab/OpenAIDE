# OpenAIDE System Notifications

This UI-side companion presents local operating-system notifications for the
OpenAIDE workspace extension. It is installed automatically as an OpenAIDE
dependency and runs locally when the workspace is in WSL, SSH, or a Dev
Container.

Run **OpenAIDE: Test System Notification** from the Command Palette to verify
desktop delivery. Failures are recorded in the **OpenAIDE Notifications**
output channel.
