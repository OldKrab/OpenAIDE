# Subagent Requests Remain Task-Wide

Status: accepted

A permission request or question originating from a Subagent has one Task-wide actionable presentation above whichever history the user is inspecting, identified by its originating Subagent and Tool. The originating Subagent History retains the linked activity and final outcome but not a second response control, so hidden child work cannot block the Task invisibly and concurrent presentations cannot submit conflicting answers.
