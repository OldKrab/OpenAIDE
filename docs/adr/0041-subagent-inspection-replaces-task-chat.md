# Subagent Inspection Replaces Task Chat

Status: accepted

Selecting a Subagent replaces Task Chat with that Subagent's observational history at every viewport width. OpenAIDE uses one explicit switching and return model rather than maintaining separate wide split-panel and narrow replacement layouts; the inspected surface clearly identifies the Subagent, exposes no Composer without an advertised input capability, and provides an easy return to the parent Task. Subagents remain children of the Task and do not become navigation entries or independent Task pages.
