# Agent-confirmed deletion and history reconciliation

Explicit Delete removes an Open or Archived Task or unadopted Native Session only after its Agent confirms removal from Agent history; rejection or an unknown outcome retains the local entry with explicit recovery. This supersedes ADR 0015's local-first deletion, because hiding a failed remote deletion would misrepresent success. Delete is capability-gated and distinct from reversible OpenAIDE Archive; Agent retention, including Codex thread archiving, is not a promise of permanent erasure. Active work requires an additional confirmation, then the Agent decides whether deletion can proceed.

General missing-session reconciliation removes the corresponding local entry and saved history, including Archived Tasks, on authoritative missing evidence. Reuse ordinary missing responses and existing listing refreshes that genuinely complete the same Agent/workspace/filter scope; incomplete listings cannot prove absence. This intentionally gives Agent history removal precedence over retaining orphaned local Chat. Keep bounded discovery and add no deletion-specific durable recovery ledger or extra validation requests: cleanup after an interrupted deletion can wait for an ordinary complete scan. Existing durable Task tombstone/purge recovery handles local cleanup once committed. Referenced files, worktrees, and temporary-upload lifetimes remain independent of Task-history deletion.
