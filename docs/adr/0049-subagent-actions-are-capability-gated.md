# Subagent Actions Are Capability-Gated

Status: accepted

Subagent History is observational by default and presents no Composer or private Codex messaging extension. While a selected Subagent is running, OpenAIDE shows one Stop Subagent action only when that child positively advertises a supported targeted cancellation or close mechanism; stopping cascades to descendants but not to the Main Agent or siblings, and durable history remains. A future standard child-input capability requires a new product decision rather than silently activating dormant UI.

Users may quote visible Subagent History into Main Agent Chat through the ordinary Quote model. The action explicitly switches to Main Agent Chat and inserts an editable quote into its Composer without creating a durable source relationship or implying that the child received a message.
